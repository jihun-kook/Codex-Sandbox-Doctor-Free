# Codex Sandbox Doctor Free

**Free Windows Codex CLI Sandbox Error Diagnostic Tool**

A free diagnostic utility for Windows users experiencing OpenAI Codex CLI execution errors.

Does Codex open normally, but terminal commands fail with errors such as `helper_unknown_error`, `setup refresh had errors`, or `os error 32`?

Codex Sandbox Doctor Free helps identify common sandbox execution problems by inspecting your installed Codex CLI environment and historical diagnostic logs.

**Free to download. No subscription.**

**[Download Codex Sandbox Doctor Free ZIP](https://github.com/jihun-kook/Codex-Sandbox-Doctor-Free/raw/refs/heads/main/CodexSandboxDoctor-Free.zip)**

After downloading:

1. Extract the ZIP file.
2. Double-click `CodexSandboxDoctor-Free.exe`.
3. Select English or Korean.
4. Click **Run Free Diagnostic**.
5. Click **View Report** to review your results.

The ZIP includes an offline HTML user guide with four real application screenshots and step-by-step explanations in English and Korean.

## Free Features

- Detect installed Codex CLI and its version.
- Locate the Codex executable.
- Inspect Windows sandbox diagnostic logs.
- Identify common execution error messages.
- Count historical error records.
- Display related process information.
- Generate diagnostic reports.
- Keep existing projects, sessions, and Codex configuration unchanged during diagnostics.

### Important

A successful diagnostic does not mean Codex has been repaired. Historical error counts are not proof that the errors are occurring now.

Free does not perform automatic recovery or generate verified recovery launch commands.

## Supported Environment
